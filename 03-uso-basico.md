# Uso básico

Para iniciar ExemploSoft:

```bash
npm start
```

### Crear unha nota
```bash
exemplosoft add "Mercar leite"
```

### Listar notas
```bash
exemplosoft list
```

### Eliminar unha nota
```bash
exemplosoft remove 1
```
