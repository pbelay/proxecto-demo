# Uso básico

Para iniciar ExemploSoft:

```bash
npm start
```

### Crear unha nota
```bash
exemplosoft add "Mercar leite"
```

### Listar notas
```bash
exemplosoft list
```

### Eliminar unha nota
```bash
exemplosoft remove 1
```

### Atallos utiles de Git
```-git status: ver estado
    -git log --online : historial cuerso
```
